## 1. 产品概述

### 1.1 产品定位

**AI中医健康管理平台** —— 基于AI视觉识别技术与中医理论，为用户提供舌诊、面诊、体质分析、健康问答等全方位健康调理建议的智能SaaS平台。

### 1.2 核心价值

| 用户群体 | 核心价值 |
|---------|---------|
| 用户 | 手机拍照即可获取中医健康调理参考，建立个人健康档案，享受个性化健康指导 |
| 推广者 | 通过社交分享获得持续被动收入 |
| 平台 | 通过AI降低中医健康服务门槛，构建用户健康数据资产 |

### 1.3 产品目标

| 目标类型 | 具体目标 | 衡量指标 |
|---------|---------|---------|
| 产品目标 | 上线AI健康分析全功能 | 舌诊+面诊+体质测试+健康问答完整闭环 |
| 商业目标 | 验证付费商业模式 | 付费转化率 ≥ 5% |
| 增长目标 | 建立推广裂变体系 | 推广用户带来 ≥ 30% 新用户 |
| 技术目标 | 支持百万用户架构 | 接口响应 ≤ 500ms，可用性 ≥ 99.9% |

## 4. 使用场景

### 场景1：用户注册

```
用户打开H5页面 → 点击"注册" → 输入用户名/手机号+密码 
→ 注册成功 → 自动登录 → 自动开通推广员 → 跳转首页
```

### 场景2：AI舌诊分析

```
用户登录 → 进入舌诊页面 → 查看拍摄指引 → 拍照/上传照片 
→ 填写性别年龄 → 提交分析 → 同步等待AI分析 
→ 显示分析结果 → 查看完整报告（消耗次数）
```

### 场景3：用户使用面诊功能

```
用户进入面诊页面 → 查看拍摄指引 → 拍摄面部照片
→ 填写性别年龄 → 上传照片 → 同步等待AI分析 
→ 显示面部特征分析 → 查看完整报告
```

### 场景4：用户进行体质测试

```
用户进入体质测试 → 回答问卷题目（约30题）
→ 系统分析体质类型 → 生成体质报告
→ 查看调理建议 → 获取个性化养生方案
```

### 场景5：用户咨询健康问答

```
用户进入健康问答 → 创建会话 → 输入健康问题
→ AI实时回答 → 可继续追问 → 保存问答记录
```

### 场景6：用户使用推广功能

```
用户注册 → 自动成为推广员 → 获得推广码/海报 
→ 分享到微信群 → 新用户通过推广码注册 
→ 新用户付费 → 推广员获得佣金 
→ 推广员申请提现 → 平台审核 → 打款
```

### 场景7：用户联系客服

```
用户进入消息中心 → 点击客服 → 自动创建会话
→ 发送消息/图片 → 客服回复 → 评价客服
```

## 11. 风险分析

| 风险类型 | 风险描述 | 影响 | 概率 | 应对措施 |
|---------|---------|------|------|---------|
| 合规风险 | AI健康建议被认定为医疗行为 | 高 | 中 | 添加免责声明，避免诊断性用语 |
| 技术风险 | AI识别准确率不足 | 高 | 中 | 多模型融合，持续优化Prompt |
| 市场风险 | 用户不愿为AI分析付费 | 高 | 中 | 免费体验+付费查看模式 |
| 成本风险 | AI调用成本过高 | 中 | 中 | 图片压缩、结果缓存、成本控制 |
| 推广风险 | 多级分销被认定为传销 | 高 | 低 | 只做一级返佣，合规纳税 |
| 支付风险 | 支付通道被封 | 高 | 低 | 多支付通道备份（余额支付已实现） |
| 数据风险 | 用户健康数据泄露 | 高 | 低 | 加密存储、访问控制、审计日志 |
| 内容风险 | AI回答出现错误医疗建议 | 高 | 中 | 建立内容审核机制，设置回答边界 |
