## 8. 异常处理

### 8.1 AI分析失败

```
异常：AI服务调用失败
处理：
1. 自动重试3次（间隔5s、10s、20s）
2. 仍失败则记录错误日志
3. 更新任务状态为"失败"
4. 通知用户"分析失败，请重试"
5. 不扣费
```

### 8.2 支付超时

```
异常：订单30分钟未支付
处理：
1. 定时任务扫描超时订单
2. 更新订单状态为"已取消"
3. 释放库存（如有）
4. 不解锁报告
```

### 8.3 支付回调失败

```
异常：微信回调通知失败
处理：
1. 微信会重试通知（共5次）
2. 同时提供主动查询接口
3. 定时任务补偿查询未支付订单
```

### 8.4 提现失败

```
异常：微信打款失败
处理：
1. 记录失败原因
2. 更新提现状态为"打款失败"
3. 解冻佣金（退回账户）
4. 通知推广员重新申请
```

## 6. 补偿机制

### 6.1 支付补偿

```php
// 定时任务：补偿查询未支付订单
class PaymentCompensationCommand extends Command
{
    public function handle()
    {
        // 查询创建超过5分钟但状态仍为"待支付"的订单
        $orders = Order::where('status', 0)
            ->where('created_at', '<', now()->subMinutes(5))
            ->get();

        foreach ($orders as $order) {
            // 主动查询支付状态
            $status = $this->paymentService->queryStatus($order->order_no);
            
            if ($status === 'paid') {
                // 更新订单状态
                $this->paymentService->handlePaymentSuccess($order);
            }
        }
    }
}
```

### 6.2 佣金补偿

```php
// 定时任务：结算冻结超过7天的佣金
class CommissionSettleCommand extends Command
{
    public function handle()
    {
        Commission::where('status', 0)
            ->where('frozen_at', '<', now()->subDays(7))
            ->update(['status' => 1, 'settled_at' => now()]);
    }
}
```

## 7. 事务边界

### 7.1 支付成功事务

```
BEGIN TRANSACTION;
1. 更新订单状态 → 已支付
2. 更新支付记录 → 成功
3. 解锁分析报告
4. 计算推广佣金
5. 发送支付通知
COMMIT;
```

### 7.2 提现成功事务

```
BEGIN TRANSACTION;
1. 更新提现状态 → 打款成功
2. 更新推广员已提现金额
3. 更新佣金状态 → 已提现
COMMIT;
```
