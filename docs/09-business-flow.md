### 1.4 分析次数扣除逻辑

```php
// 实际逻辑（AnalysisController.php）
public function analyze(Request $request)
{
    $user = $request->user();
    
    // 1. 检查分析次数
    if ($user->analysis_times <= 0) {
        return response()->json(['message' => '分析次数不足，请购买次数包'], 402);
    }
    
    // 2. 上传文件（直接上传到服务器本地存储）
    $path = $request->file('image')->store('analysis', 'public');
    
    // 3. 同步调用AI服务（使用AI服务优先级链）
    $result = $this->aiService->analyze($path, $request->type);
    
    // 4. 扣减分析次数
    $user->decrement('analysis_times');
    
    // 5. 保存分析任务和报告
    $task = AnalysisTask::create([...]);
    $report = AnalysisReport::create([...]);
    
    return response()->json([
        'task_id' => $task->id,
        'summary' => $report->summary,  // 摘要（免费显示）
        'is_paid' => false,
    ]);
}
```

### 3.5 注册自动激活推广员

```php
// 实际逻辑（AuthController.php 注册方法）
public function register(Request $request)
{
    // 1. 创建用户
    $user = User::create([
        'account' => $request->account,
        'password' => Hash::make($request->password),
        'parent_id' => $request->parent_id,  // 推广人ID
    ]);
    
    // 2. 自动激活推广员身份
    $user->is_promoter = 1;
    $user->save();
    
    // 3. 创建推广员记录
    Promoter::create([
        'user_id' => $user->id,
        'code' => $this->generateCode(),
    ]);
    
    // 4. 发放注册试用次数（如配置开启）
    if (config('app.register_grant_times', 0) > 0) {
        $user->increment('analysis_times', config('app.register_grant_times'));
        $user->user_registered_granted = true;
        $user->save();
    }
    
    // 5. 创建Token
    $token = $user->createToken('auth-token')->plainTextToken;
    
    return response()->json(['token' => $token]);
}
```

## 10. 异常处理

### 10.1 AI分析失败

```
异常：AI服务调用失败
处理：
1. 自动切换下一个优先级的AI模型（豆包 → DeepSeek → ...）
2. 所有模型都失败则记录错误日志
3. 更新任务状态为"失败"
4. 通知用户"分析失败，请重试"
5. 不扣费（分析次数不减少）
```

### 10.2 支付超时

```
异常：订单30分钟未支付
处理：
1. 定时任务扫描超时订单
2. 更新订单状态为"已取消"
3. 释放库存（如有）
4. 不解锁报告
```

### 10.3 支付回调失败

```
异常：微信回调通知失败
处理：
1. 微信会重试通知（共5次）
2. 同时提供主动查询接口
3. 定时任务补偿查询未支付订单
```

### 10.4 提现失败

```
异常：打款失败
处理：
1. 记录失败原因
2. 更新提现状态为"打款失败"
3. 解冻佣金（退回账户）
4. 通知推广员重新申请
```

## 11. 补偿机制

### 11.1 支付补偿

```php
// 定时任务：补偿查询未支付订单
class PaymentCompensationCommand extends Command
{
    public function handle()
    {
        // 查询创建超过5分钟但状态仍为"待支付"的订单
        $orders = Order::where('status', 0)
            ->where('created_at', '<', now()->subMinutes(5))
            ->get();

        foreach ($orders as $order) {
            // 主动查询支付状态
            $status = $this->paymentService->queryStatus($order->order_no);
            
            if ($status === 'paid') {
                // 更新订单状态
                $this->paymentService->handlePaymentSuccess($order);
            }
        }
    }
}
```

### 11.2 佣金结算

```php
// 定时任务：结算冻结超过7天的佣金
class CommissionSettleCommand extends Command
{
    public function handle()
    {
        Commission::where('status', 0)
            ->where('created_at', '<', now()->subDays(7))
            ->update(['status' => 1, 'settled_at' => now()]);
    }
}
```

## 12. 事务边界

### 12.1 支付成功事务

```
BEGIN TRANSACTION;
1. 更新订单状态 → 已支付
2. 更新支付记录 → 成功
3. 解锁分析报告
4. 计算推广佣金
COMMIT;
```

### 12.2 提现成功事务

```
BEGIN TRANSACTION;
1. 更新提现状态 → 打款成功
2. 更新推广员已提现金额
3. 更新佣金状态 → 已提现
COMMIT;
```
