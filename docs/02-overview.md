## 1. 项目定位

**AI中医健康管理平台** —— 基于AI视觉识别技术，为用户提供中医舌诊、面诊、体质分析等健康调理建议的SaaS平台。

### 1.1 产品愿景

成为中国领先的AI中医健康管理平台，让每个人都能随时随地获取专业的中医健康调理参考。

### 1.2 产品使命

- 降低中医健康服务门槛
- 普及中医养生文化
- 帮助用户建立健康档案，实现长期健康管理

### 1.3 产品阶段

| 阶段 | 时间 | 目标 |
|------|------|------|
| Phase 1 MVP | 第1-3月 | 验证商业模式 |
| Phase 2 增长期 | 第4-6月 | 推广裂变+会员体系 |
| Phase 3 扩展期 | 第7-9月 | 多AI功能+CMS |
| Phase 4 生态期 | 第10-12月 | 医生合作+商城 |

## 2. 项目目标

### 2.1 北极星指标

**月活跃付费用户数** —— 衡量平台商业价值的核心指标

### 2.2 关键结果（KR）

| 目标类型 | 具体目标 | 衡量指标 |
|---------|---------|---------|
| 产品目标 | 上线AI舌诊核心功能 | 用户上传照片→AI分析→付费查看报告 |
| 商业目标 | 验证付费商业模式 | 付费转化率 ≥ 5% |
| 增长目标 | 建立推广裂变体系 | 推广用户带来 ≥ 30% 新用户 |
| 技术目标 | 支持百万用户架构 | 接口响应 ≤ 500ms，可用性 ≥ 99.9% |

### 2.3 商业目标拆解

```
月活跃付费用户 = 新用户 × 付费转化率 + 老用户 × 复购率

目标：6个月后月活跃付费用户 ≥ 5000人
- 新用户：2000人/月 × 5%付费 = 100人
- 老用户：10000人 × 40%复购 = 4000人
```

## 4. 业务价值

### 4.1 对用户

| 价值点 | 说明 |
|--------|------|
| 便捷 | 手机拍照即可获取健康分析，无需去医院排队 |
| 经济 | 相比中医门诊，成本极低（9.9元/次） |
| 持续 | 建立健康档案，追踪身体变化趋势 |

| 价值点 | 说明 |
|--------|------|
| 高频 | 健康需求是持续性的，用户会反复使用 |
| 数据 | 积累用户健康数据，形成竞争壁垒 |
| 裂变 | 推广返佣机制驱动用户增长 |

### 4.3 对社会

| 价值点 | 说明 |
|--------|------|
| 普及 | 让更多人了解中医养生文化 |
| 预防 | 帮助用户早发现健康问题，及时调理 |

## 6. 商业模式

### 6.1 商业模式画布

```
┌─────────────────────────────────────────────────────┐
│                    商业模式画布                        │
├─────────────────────────────────────────────────────┤
│                                                     │
│  收入来源                                            │
│  ├── 单次查看付费：9.9元/次                          │
│  ├── 次数包：69元/10次（6.9元/次）                   │
│  ├── 月度会员：39元/月（每天3次免费）                 │
│  └── 年度会员：299元/年（无限次）                    │
│                                                     │
│  成本结构                                            │
│  ├── AI调用成本：约0.5-1元/次                        │
│  ├── 对象存储：约0.01元/张                          │
│  ├── 支付手续费：微信0.6%                           │
│  ├── 推广佣金：消费金额的15-20%                     │
│  └── 服务器成本：约2000元/月（初期）                 │
│                                                     │
│  利润模型                                            │
│  单次付费：9.9 - 1(AI) - 0.06(支付) = 8.84元        │
│  推广场景：8.84 - 1.5(佣金) = 7.34元                 │
│  毛利率：约 75-85%                                   │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 6.2 定价策略

| 产品 | 价格 | 说明 |
|------|------|------|
| 单次查看 | 9.9元 | 尝鲜价格，降低决策门槛 |
| 10次包 | 69元 | 6.9元/次，鼓励囤货 |
| 月度会员 | 39元/月 | 每天3次免费，超出按次优惠 |
| 年度会员 | 299元/年 | 无限次使用，最优惠 |

### 6.3 推广返佣

| 推广员等级 | 佣金比例 | 升级条件 |
|-----------|---------|---------|
| 初级推广员 | 15% | 默认等级 |
| 高级推广员 | 20% | 累计邀请 ≥ 50人且消费 ≥ 20人 |

## 8. 非功能需求

### 8.1 性能需求

| 指标 | 目标 | 说明 |
|------|------|------|
| 首页加载 | ≤ 2s | 首屏加载时间 |
| 接口响应时间 | ≤ 500ms（P95） | API响应时间 |
| AI分析时间 | ≤ 30s（含排队） | 从提交到出结果 |
| 并发支持 | ≥ 1000 QPS | 系统并发能力 |

### 8.2 可用性需求

| 指标 | 目标 | 说明 |
|------|------|------|
| 系统可用性 | ≥ 99.9% | 月度可用性 |
| 数据恢复RPO | ≤ 1小时 | 数据恢复点目标 |
| 故障恢复RTO | ≤ 4小时 | 故障恢复时间目标 |

### 8.3 安全需求

| 指标 | 目标 |
|------|------|

## 9. 风险分析

### 9.1 高风险

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| AI健康建议被认定为医疗行为 | 高 | 添加免责声明，避免诊断性用语，咨询法务 |
| AI识别准确率不足 | 高 | 多模型融合，持续优化Prompt，增加问卷补充 |
| 用户不愿为AI分析付费 | 高 | 免费体验+付费查看模式，提供真实价值 |

### 9.2 中风险

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| AI调用成本过高 | 中 | 图片压缩、结果缓存、成本控制、多模型比价 |
| 大厂推出类似产品 | 中 | 快速迭代，建立用户粘性，积累数据壁垒 |

### 9.3 低风险

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| 多级分销被认定为传销 | 低 | 只做一级返佣，合规纳税 |
| 支付通道被封 | 低 | 多支付通道备份 |
| 用户健康数据泄露 | 低 | 加密存储、访问控制、审计日志 |
